GEA-H TV - Régie Pro Priorités

Fonctionnement :
1. La playlist normale joue les vidéos publiées une après l'autre, en boucle.
2. Lorsqu'un programme planifié arrive à son heure, il prend le relais automatiquement.
3. À la fin du programme, la playlist normale reprend au même endroit.
4. Depuis Admin > Régie Pro immédiate, l'admin peut couper l'antenne pour diffuser une information, une promotion, une vidéo, une musique, un reportage ou un live.
5. L'intervention admin a la priorité absolue, puis la programmation, puis la playlist normale.

Pages ajoutées :
- /admin/tv-control-room.php : régie immédiate.
- /admin/tv-programme-pro.php : grille horaire.
- /admin/geah-tv.php : bibliothèque vidéo.
- /admin/tv-live-studio.php : direct / live.
- /admin/tv-ai-studio.php : scripts et séries IA.

Important :
- Les vidéos doivent être publiées pour entrer dans la playlist.
- Les liens YouTube, MP4, HLS .m3u8, Vimeo, Facebook sont acceptés selon les limites d'autoplay de chaque plateforme.
- Pour un direct fiable, utiliser OBS, HLS ou YouTube Live puis coller le lien dans la régie.
