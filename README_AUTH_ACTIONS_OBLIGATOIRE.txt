GEA-H — Authentification obligatoire pour les actions

Modifications ajoutées :
- Les visiteurs peuvent voir l'accueil, les biens, la recherche, le showroom et GEA-H TV.
- Pour toute action importante, une connexion/inscription est obligatoire.
- Les visiteurs qui cliquent sur une action voient une fenêtre : Connexion obligatoire, avec Connexion / Inscription.
- Après connexion, l'utilisateur est renvoyé vers l'action demandée.
- Les utilisateurs connectés peuvent toujours regarder les biens et GEA-H TV, puis se déconnecter.

Actions protégées :
- Déposer une annonce
- Réserver / payer un bien, hôtel ou résidence
- Demander une visite
- Commander / payer un article
- Studio intérieur 3D
- Ville 3D
- Maison 3D + plan imprimable
- Recharge GEA-H Bank
- Téléchargement / impression de plan payé
- Formulaires POST publics hors inscription/connexion

Les pages vitrine restent visibles sans compte.
