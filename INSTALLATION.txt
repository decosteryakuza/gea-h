NOUVEAU : LOTISSEMENT IA (Admin > Lotissement IA)
--------------------------------------------------------
- "Analyser un terrain avec l'IA" : téléverse une IMAGE (photo, vue
  satellite ou plan). Nécessite une clé OpenAI (gpt-4o) ou Gemini
  (gemini-1.5) branchée dans API Manager (le modèle doit lire les images).
- "Générateur de plan conceptuel" : dessine un découpage en lots + voiries
  et liste des coins de bornes INDICATIFS (mètres, + GPS approximatif si
  point de référence fourni).
- IMPORTANT : outil d'aide à la conception uniquement. Le bornage réel et
  les coordonnées GPS définitives exigent un levé topographique
  (GPS RTK / station totale), un traitement AutoCAD + Covadis (ou KAJO)
  et la validation d'un GÉOMÈTRE-EXPERT AGRÉÉ.
- Le dossier "uploads/" doit être accessible en écriture (pour les images).

--------------------------------------------------------
NOUVEAU : TERRAIN VISION 3D (Admin > Terrain Vision 3D)
--------------------------------------------------------
- Génère une vue 3D interactive du morcellement (par dimensions de lot
  OU par nombre de parcelles) : parcelles, voiries, numéros, bornes.
- Glisser = tourner, molette/pincer = zoomer.
- Nécessite une connexion internet (librairie 3D Three.js chargée via CDN).
- Visualisation CONCEPTUELLE non géoréférencée. Relief réel = levé
  topographique ; bornage légal = géomètre-expert agréé.
