GEA-H TV PRO — Chaîne Internet

Objectif
- Transformer GEA-H TV en véritable chaîne TV Internet.
- Permettre la programmation par heure/jour.
- Diffuser interviews, reportages, documentaires, promotions, séries, musiques, publicités.
- Permettre la création de scripts et séries avec assistance IA.
- Préparer le live depuis OBS, smartphone RTMP, YouTube Live, Facebook Live ou flux HLS.

Nouveaux modules Admin
1. Admin > Gestion GEA-H TV
   - Ajout des vidéos depuis fichier ou lien.
   - Types enrichis : émission, interview, reportage, documentaire, série, musique, promotion, live.

2. Admin > Programmation TV Pro
   - Programme un contenu à une date et une heure.
   - Durée en minutes.
   - Répétition : une fois, chaque jour, chaque semaine.
   - Priorité de diffusion.
   - Si aucun lien vidéo n'est donné, le système peut diffuser un slide texte avec voix navigateur.

3. Admin > Studio IA TV
   - Création de scripts d'émissions, interviews, reportages, documentaires, séries.
   - Possibilité de publier le script comme contenu TV.
   - Possibilité d'ajouter ensuite une vidéo générée ou montée.

4. Admin > Régie Live
   - Active un direct qui passe en priorité sur la chaîne.
   - Compatible avec lien YouTube, Facebook public, Vimeo, HLS .m3u8, MP4, Cloudinary.
   - Pour TikTok, utiliser de préférence un relais via OBS ou une solution live qui fournit un lien réutilisable.

Fonctionnement de la chaîne
- Si un live est actif : il passe en premier.
- Sinon si une émission programmée est en cours : elle passe en priorité.
- Sinon GEA-H TV enchaîne les vidéos publiées, les biens avec vidéos, les publicités et les contenus IA.

Monétisation
- Publicités vidéo.
- Émissions sponsorisées.
- Mise en avant de biens.
- Série sponsorisée par partenaire.
- Diffusion d'interviews payantes.
- Production vidéo assistée IA pour partenaires.

À configurer plus tard
- API vidéo IA : Runway, Creatomate, HeyGen ou autre.
- Voix IA professionnelle : ElevenLabs, OpenAI TTS ou autre.
- Stockage vidéo : Cloudinary ou Cloudflare R2.
- Live avancé : serveur RTMP/HLS ou plateforme de diffusion.
