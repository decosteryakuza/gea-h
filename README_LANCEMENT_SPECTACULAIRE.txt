GEA-H - Lancement spectaculaire

Ajouts :
1. Compte à rebours réglable depuis Admin > Réglages.
2. A 00:00, la vidéo de présentation programmée depuis Admin démarre automatiquement.
3. A la fin de la vidéo, artifices/confettis + ouverture du site en mode public.
4. Le bouton Plein écran permet d'afficher l'écran de lancement sur une TV ou vidéoprojecteur.
5. En mode maintenance, le site reste verrouillé mais l'écran de présentation peut continuer à diffuser.

Réglages importants :
- Admin > Réglages > Date lancement
- Admin > Réglages > Vidéo de lancement
- Admin > Réglages > Après la vidéo de lancement, ouvrir automatiquement le site en mode public
- Admin > Réglages > Activer les artifices / confettis

Test conseillé : mettre une date de lancement à 2 minutes, charger une courte vidéo, ouvrir la page publique en plein écran et vérifier l'enchaînement.
