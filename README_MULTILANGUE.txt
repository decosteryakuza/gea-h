GEA-H MULTILANGUE AJOUTÉ

Fonctions ajoutées :
- Sélecteur de langue flottant visible sur le site : FR / EN / ES / PT / AR.
- Français par défaut.
- Mémorisation de la langue choisie dans le navigateur.
- Traduction automatique via Google Translate si disponible.
- Traduction locale de secours pour les menus essentiels.
- Direction RTL pour l'arabe.
- Assistant IA : la langue choisie est envoyée à ask.php pour répondre dans la même langue.

Important : Google Translate nécessite Internet côté visiteur. Si le script Google est bloqué, les libellés principaux restent traduits grâce au dictionnaire local.
