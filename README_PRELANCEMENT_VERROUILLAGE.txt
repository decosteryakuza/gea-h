GEA-H - MODE PRÉ-LANCEMENT VERROUILLÉ

Ce module ajoute un verrouillage public complet pour préparer le lancement officiel.

FONCTIONNEMENT
1. Quand le mode du site est réglé sur "Pré-lancement" ou "Maintenance", les visiteurs ne voient plus les pages internes.
2. Toutes les pages publiques sensibles sont redirigées vers l'écran de pré-lancement.
3. Les administrateurs peuvent toujours se connecter via /admin/login.php et travailler sur le site.
4. Une fois connecté comme admin, vous pouvez voir et tester le site normalement.

CE QUI EST AJOUTÉ
- Écran de pré-lancement premium.
- Compte à rebours jusqu'au jour J.
- Vidéo de présentation de lancement.
- Assistant IA vocal de présentation via le navigateur.
- Formulaire pour collecter les emails des personnes intéressées.
- Bouton d'accès administration.
- Anti-indexation activable pour éviter que Google référence le site avant le lancement.

CONFIGURATION
Allez dans : Admin > Réglages & Contact

Vous pouvez modifier :
- Mode du site : Pré-lancement / Public / Maintenance.
- Date et heure du lancement.
- Message de pré-lancement.
- Vidéo de lancement : URL ou upload vidéo.
- Texte lu par l'assistant IA.
- Activation/désactivation de la voix IA.

LE JOUR J
1. Connectez-vous à /admin/login.php.
2. Allez dans Admin > Réglages & Contact.
3. Ajoutez ou remplacez la vidéo de lancement.
4. Vérifiez le texte de présentation vocale IA.
5. Quand vous êtes prêt, passez le mode de "Pré-lancement" à "Public".
6. Le site officiel devient visible.

IMPORTANT
Ce verrouillage protège l'affichage public, mais il ne remplace pas une vraie sécurité serveur. Gardez les mots de passe admin forts et ne partagez pas les accès.
