GEA-H — Connexion email / numéro et mots de passe temporaires

1) Connexion
L'utilisateur peut se connecter avec :
- son email enregistré ;
- ou son numéro de téléphone enregistré.

Le système reconnaît automatiquement si le compte est :
- Super Admin / Admin ;
- DG ;
- Agent ;
- Comptable ;
- RH ;
- Support ;
- Client / utilisateur simple.

Après connexion, il est redirigé vers l'espace correspondant.

2) Mots de passe temporaires des agents/personnel
Quand l'admin crée un agent avec son numéro, le mot de passe temporaire est :

GEAH@ + les 4 derniers chiffres du numéro

Exemple :
Numéro : 07 58 02 86 97
Mot de passe temporaire : GEAH@8697

L'agent devra modifier son mot de passe à la première connexion.

3) Super Admin par défaut
Compte initial : admin@gea-holding.net
Mot de passe initial : GEA-Admin-2026
À modifier dès la première connexion.

4) Sécurité
- Mot de passe minimum : 8 caractères.
- Les mots de passe sont enregistrés en version hachée, pas en clair.
- Connexion possible par email ou téléphone.
- Les permissions restent gérées depuis Admin → Utilisateurs & rôles.

5) Réinitialisation VPS
En cas de piratage ou perte d'accès, utiliser le script de reset prévu dans le dossier admin/cli ou le guide sécurité si présent.
