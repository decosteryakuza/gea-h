GEA-H V21 - Administration globale, multilingue, IA vocale, import intelligent et Studio 3D avancé

Ajouts principaux :
1. Centre de gestion global Admin
- Tous les contenus ajoutés sur le site peuvent être gérés depuis Admin.
- Actions : voir, modifier, supprimer, archiver, restaurer, publier, désactiver, mettre en avant.
- Suppression vers corbeille au lieu d’effacement direct.
- Historique/audit par module.

2. Multilingue + dialectes africains + IA vocale
- Langues internationales et africaines.
- Détection automatique de langue.
- Réponse texte + vocale.
- Commandes vocales.
- Correction manuelle par Admin pour les dialectes approximatifs.

3. Import intelligent
- Ajout de biens manuellement, par photo, capture, vidéo ou lien.
- Ajout GEA-H TV par fichier ou lien.
- Ajout plans/photos pour Studio 3D, Smart City et Lotissement IA.

4. Studio 3D / Smart City / Lotissement IA
- Import plan/photo/terrain/pièce.
- IA avancée pour proposer aménagement, décoration, lotissement, urbanisation.
- Exports payants : plan, image, vidéo, dossier projet.
- Gratuit possible pour certains agents GEA avec permission admin.

5. Permissions
- Lotissement IA réservé Admin par défaut.
- Admin peut donner permission à agents ou personnel autorisé.
- Tout le menu public reste visible, mais les actions sensibles restent protégées.
