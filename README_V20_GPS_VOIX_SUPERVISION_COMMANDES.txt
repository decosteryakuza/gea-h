GEA-H V20 — GPS, commandes vocales, supervision et communication interne

Ajouts principaux :
1. Admin > Départ GPS chauffeur
- Saisie ville/quartier/coordonnées/lieux enregistrés.
- Commande vocale via navigateur compatible.
- Ouverture Google Maps en itinéraire.
- Historique des départs GPS.

2. Admin > Ordres vocaux IA
- Dictée vocale des ordres.
- Lecture voix haute.
- Statut : lu, accepté, en cours, rendu, terminé, besoin de précision.
- Historique hiérarchique des instructions et rapports.

3. Admin > Centre de commandement
- Vue globale des rôles, permissions, tâches, ordres et trajets.
- Le Super Admin garde la main sur les autorisations depuis Utilisateurs & Rôles.

4. Messagerie interne
- Envoi interne texte, email, SMS/WhatsApp selon API configurées.
- Dictée vocale et lecture voix haute ajoutées.

Sécurité :
- Aucune écoute secrète : la voix n’est utilisée que lorsque l’utilisateur clique volontairement sur le micro.
- Les accès sensibles restent protégés par permissions.
- Les journaux servent au suivi professionnel des ordres, tâches et rapports.
